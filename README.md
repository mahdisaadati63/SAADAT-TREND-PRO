# ⚡ SAADAT TREND PRO

**سیستم هوشمند تحلیل Price Action و ICT برای پلتفرم Quotex**

این پروژه یک افزونه Google Chrome است که با استفاده از تکنولوژی **Manifest V3** توسعه داده شده است. هدف این افزونه تحلیل نمودارهای معاملاتی (به ویژه در کوئوتکس) بدون دخالت در معاملات (بدون اتوترید) و فقط برای **صدور سیگنال‌های باکیفیت بالا** است.

---

## 🚀 روش راه‌اندازی و نصب افزونه

از آنجا که این افزونه در حال توسعه است و هنوز در Chrome Web Store منتشر نشده، باید آن را به صورت دستی (حالت توسعه‌دهنده) نصب کنید:

### ۱. دریافت کدها
شما می‌توانید فایل فشرده (`.zip`) کدها را دانلود کنید یا با استفاده از گیت، مخزن را کلون کنید:
```bash
git clone <لینک-مخزن-شما>
```
دقت کنید که کدهای اصلی افزونه درون پوشه‌ی `saadat-trend-pro` قرار دارند.

### ۲. نصب در گوگل کروم
1. مرورگر **Google Chrome** را باز کنید.
2. در نوار آدرس عبارت `chrome://extensions/` را تایپ کنید و Enter بزنید.
3. در گوشه بالا سمت راست صفحه باز شده، سوییچ **Developer mode** (حالت توسعه‌دهنده) را روشن کنید.
4. در نوار ظاهر شده در بالای صفحه، روی دکمه‌ی **Load unpacked** کلیک کنید.
5. به مسیری که کدها را ذخیره کرده‌اید بروید، روی پوشه `saadat-trend-pro` (پوشه‌ای که فایل `manifest.json` مستقیماً داخل آن است) کلیک کنید و **Select Folder** را بزنید.
6. افزونه با موفقیت نصب شده و آیکون آن در مرورگر شما قابل مشاهده خواهد بود.

## 🛠 نکات فنی و معماری سیستم

این سیستم به گونه‌ای ماژولار طراحی شده تا در آینده قابلیت اتصال به **سرور اختصاصی پایتون** را داشته باشد.

### ۱. استخراج لحظه‌ای قیمت (Live Price Extraction)
همان‌طور که می‌دانید، کوئوتکس چارت‌ها را با Canvas رندر می‌کند که خواندن مستقیم از آن ممکن نیست. این افزونه برای حل این مشکل از دو روش استفاده می‌کند:

* **روش اصلی (WebSocket Interception):**
فایل `injected-websocket.js` در لایه‌ی اصلی سایت تزریق می‌شود. این فایل، آبجکت `WebSocket` مرورگر را به اصطلاح "Monkey-patch" می‌کند. به این ترتیب تمام پیام‌های قیمتی که از سرور کوئوتکس به سیستم کاربر می‌رسند (تیک‌داده‌ها) بدون ثانیه‌ای تأخیر شنود شده و برای افزونه ارسال می‌گردند.
* **روش پشتیبان (DOM Scraping Fallback):**
در فایل `chart-reader.js`، اگر سیستم نتواند اطلاعات WebSocket را به درستی بخواند، به صورت خودکار قیمت‌ها را از روی المان‌های HTML صفحه شکار می‌کند.

### ۲. ساختار موتورها
* **موتور کندل (Candle Engine):** تیک‌داده‌های دریافت‌شده را تجمیع کرده و کندل‌های استاندارد ۱ دقیقه‌ای می‌سازد.
* **موتورهای تحلیلی:** شامل Market Structure (روند)، Price Action (الگوهای کندلی)، S/R و Moving Averages.
* **موتور تولید سیگنال:** سیگنال‌ها را بر اساس وزن‌دهی (Scoring) امتیازگذاری می‌کند. فقط سیگنال‌هایی که آستانه (Threshold) لازم را داشته باشند به کاربر نمایش داده می‌شوند.
* **دیتابیس:** تمام سیگنال‌ها (بدون تغییر و بازنقاشی) جهت بک‌تست‌گیری در **IndexedDB** ذخیره می‌شوند.

## ⚙️ یکپارچگی مداوم (CI - GitHub Actions)

این مخزن به گونه‌ای تنظیم شده که در هنگام هر Commit یا Pull Request، گیت‌هاب به صورت خودکار عملیات‌های زیر را انجام می‌دهد:

1. **بررسی استانداردها (Linting):**
فایل `.github/workflows/ci.yml` با استفاده از ابزار `web-ext` ساختار `manifest.json` و فایل‌های شما را بررسی می‌کند تا مطمئن شود که هیچ خطایی برای انتشار در گوگل کروم وجود ندارد.
2. **ساخت فایل خروجی (Build Artifact):**
در صورتی که کدها سالم باشند، گیت‌هاب به طور خودکار پوشه `saadat-trend-pro` را زیپ می‌کند.
شما می‌توانید با مراجعه به بخش **Actions** در گیت‌هاب خود، همیشه آخرین نسخه‌ی آماده نصب (فایل Zip) افزونه را به راحتی دانلود کنید.

## 📅 نقشه راه آینده (ارتباط با پایتون)
هم‌اکنون تمام پردازش‌ها روی مرورگر انجام می‌شود. به دلیل ماژولار بودن کد، در گام‌های بعدی تنها با آپدیت بخش `background/service-worker.js` می‌توانیم داده‌های استخراج شده را به سرور پایتون قدرتمند شما ارسال کنیم تا پردازش‌های هوش مصنوعی و ICT فوق‌پیشرفته روی سرور انجام شده و نتایج مجدداً به افزونه کروم بازگردانده شوند.
